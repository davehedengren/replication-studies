# 184261 — Optimal Monetary Policy according to HANK (Acharya, Challe, Dogra, AER 2023)

## Why this paper is out of scope

This is a **pure theoretical / structural paper with no empirical component**. The replication package contains 20 MATLAB files (`main.m`, `plot_figs_1to3.m`, `plot_figs_4to7.m`, `plot_appendix_figs.m`, and ~16 solver scripts: `optdynamics_*`, `tcdynamics_*`, `makeec*`, `optw*`, `realpeg_dynamics_iid.m`, `optdynamics_profits.m`). There are **zero data files** — no `.csv`, `.dta`, `.xlsx`, `.mat`, or raw microdata of any kind.

The openICPSR README.pdf states this explicitly:

> ☒ This paper does not involve analysis of external data (i.e., no data are used or the only data are generated by the authors via simulation in their code).

All parameters of the HANK model are **calibrated directly in the code** (`plot_figs_4to7.m` lines 13–30):

```matlab
ec.theta  = 1 - 0.15;
ec.R      = 1.04;
ec.gambar = 2;
ec.sigy   = 0.5;
ec.kap    = 0.1;
ec.lam    = 1.1;
ec.rhoz   = 0.95^4;
ec.sigz   = 0.00582*2;
...
```

No moment matching, no SMM, no GMM objective, no estimation routine — just hard-coded numbers plugged into the model's analytical optimality conditions.

## What the paper actually produces

The full output of running `main.m` is:

1. **12 figures** (Figures 1–7 main + H.1, H.2, I.1, J.1, J.2 appendix) — impulse response functions of a linearized HANK model under utilitarian / Ramsey / NU planners, compared against a representative-agent (RANK) benchmark, a TANK benchmark, and real-peg dynamics.
2. **Three scalar parameters** printed to the console: `Upsilon`, `delta`, `varkappa` — all derived analytically from the calibrated parameters via the `optdynamics_iid.m` routine.

There are **no tables** in the paper. There are no estimated coefficients, no standard errors, no t-statistics, no regressions.

## Why it doesn't fit the Python-replication scope of this repo

This project exists to translate **empirical** econometric analyses (Stata / R / MATLAB code operating on data) into Python and verify published statistics. Papers in this repo either re-run regressions on shipped data or recompute summary statistics from shipped microdata. 184261 has neither.

To "replicate" it in Python would require a full port of the HANK / TANK / HTM solver stack: the linearized equilibrium conditions in `makeec.m`, the Ramsey FOCs in `optw.m`, the forward IRF solver in `optdynamics_iid.m`, and the corresponding HTM / PERS variants — a multi-week structural-macro port that produces a set of theoretical IRF plots with no empirical ground truth to validate against. The "correctness" check would just be "does my Python reproduce the authors' MATLAB figures?" — a code translation exercise, not a replication in the sense this repo cares about.

This is the same reason papers **130626** (structural SIR optimal-control model) and **141001** (structural Fortran+MATLAB sovereign-default model) are already on the Skipped list. 184261 is strictly more pure-theoretical than either — those at least had observable moments the model targeted; this one's parameters are just textbook calibration values.

## Decision

**Skipped.** Added to the Skipped Papers table with reason: "Pure MATLAB HANK structural model; no data, no estimation (all parameters hard-coded; only IRF figures and 3 analytical scalars)."
